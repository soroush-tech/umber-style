# Options reference

After this page you can look up any option or prop of UmberStyle: its name, type, default and effect, and which function takes it.

## Who takes which options

| Function                                                           | Takes                                                                                 |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `createEngine(theme, options)`, `createLazyEngine(options)`        | The engine options below                                                              |
| `createCache(options)`                                             | The cache options below                                                               |
| `createStyle(theme, options)` (React, Vue)                         | The engine options, and `engine`                                                      |
| `configure(options)` (React, Vue)                                  | The same as `createStyle`, and `theme`                                                |
| `createStyle(theme, options)`, `configure(options)` (React Native) | Accepted so that one call runs on both platforms. Only `theme` of `configure` is used |
| `styled(tag, options)`                                             | The styled options below                                                              |
| `<ThemeProvider />`                                                | The props below                                                                       |

An engine makes its own cache from the options that are shared with the cache. If you give the engine a `cache`, those options are taken from the cache and the engine's own are ignored.

## Engine options

| Name                | Type                                       | Default                                                                   | Effect                                                                                                                                                                                                                                      |
| ------------------- | ------------------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prefix`            | `string`                                   | the cache's prefix, else `'css'`                                          | First part of every class name and variable name. Must match `/^[a-z][a-z0-9-]*$/`, or the cache throws. With a `cache` it must be that cache's prefix, or omitted; another one throws a `TypeError`                                        |
| `suffix`            | `string`                                   | `''`                                                                      | Appended to every class name                                                                                                                                                                                                                |
| `hasLabels`         | `boolean`                                  | `true`                                                                    | Whether a style's label is part of its class name                                                                                                                                                                                           |
| `hasLayers`         | `boolean`                                  | `true`                                                                    | Whether every rule goes into a cascade layer. See [Cascade layers and overrides](cascade-layers.md)                                                                                                                                         |
| `hasDevChecks`      | `boolean`                                  | on when `process.env.NODE_ENV` is `development` and there is a `document` | Whether the cache checks the page (`findMissingStyles`) and asks the browser about each declaration it inserts (`CSS.supports`), throttled, and warns once for each. Off in production. See [Testing](testing.md#the-development-checker)   |
| `hasBaseClass`      | `boolean`                                  | `true`                                                                    | Whether a styled component's styles are split into a base class (the leading styles that do not depend on props, made once) and a props class. Without it a component has one class for its whole list. See [How it works](how-it-works.md) |
| `hasColorFallbacks` | `boolean`                                  | `true`                                                                    | Whether `alpha()` writes a fallback before the `color-mix()` value. See [Tokens](tokens.md)                                                                                                                                                 |
| `hasValueRepair`    | `boolean`                                  | `false`                                                                   | Whether the string forms of token maths that are not valid CSS (`var(--x)1F`, `-var(--x)`, `var(--x)ms`) are rewritten in each value. See [Tokens](tokens.md#string-forms-of-token-maths)                                                   |
| `hasScope`          | `boolean`                                  | `true`                                                                    | Whether `when()` and `whenScheme()` use `@scope`. Without it the rule is a plain descendant selector, which is wrong for nested themes. See [Theme conditions](theme-conditions.md)                                                         |
| `hasPruning`        | `boolean`                                  | `true`                                                                    | Whether a theme class declares only the variables that rules use. See [Tokens](tokens.md)                                                                                                                                                   |
| `alwaysDeclare`     | `readonly string[]`                        | `[]`                                                                      | Theme paths (a top-level key or a dotted path) whose variables are always declared                                                                                                                                                          |
| `cache`             | `Cache`                                    | one is made                                                               | The cache to use. Its `prefix` is the prefix of the engine too: variables and classes use the same one                                                                                                                                      |
| `rawKeys`           | `readonly string[]`                        | `['breakpoints', 'components']`                                           | Top-level theme keys that stay real values and get no variable. A list you give replaces the default                                                                                                                                        |
| `lengthKeys`        | `readonly string[]`                        | `['space', 'sizes', 'radii', 'fontSizes', 'borderWidths']`                | Top-level keys whose numbers are lengths, declared with `px`. A list you give replaces the default                                                                                                                                          |
| `modes`             | `Record<string, TokenMode>`                | none                                                                      | The mode of a token by dotted theme path: `'variable'`, `'inline'`, `'reference'` or `'raw'`. The most specific path wins, and an entry beats `rawKeys`                                                                                     |
| `registered`        | `Record<string, RegisteredSyntax \| true>` | none                                                                      | Tokens that are registered custom properties (an `@property` rule), by dotted path. `true` infers the syntax. See [Tokens](tokens.md)                                                                                                       |

`hasLayers`, `hasBaseClass`, `hasColorFallbacks`, `hasValueRepair`, `hasScope`, `hasPruning`, `suffix` and `hasLabels` are used when the engine makes its cache. `rawKeys`, `lengthKeys`, `modes`, `registered` and `alwaysDeclare` are always the engine's. The `prefix` is the cache's: a given cache sets it, and an engine `prefix` that differs from it throws a `TypeError` that names both.

`TokenMode` is `'variable' | 'inline' | 'reference' | 'raw'`. `RegisteredSyntax` is `'<color>' | '<length>' | '<number>' | '<percentage>' | '<length-percentage>' | '<angle>' | '<time>' | '*'`.

## Cache options

`createCache(options)`:

| Name                | Type      | Default                                                        | Effect                                                                                                                                     |
| ------------------- | --------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `prefix`            | `string`  | `'css'`                                                        | First part of every class name. Must match `/^[a-z][a-z0-9-]*$/`; otherwise `createCache` throws                                           |
| `suffix`            | `string`  | `''`                                                           | Appended to every class name                                                                                                               |
| `hasLabels`         | `boolean` | `true`                                                         | Whether a style's label is part of its class name                                                                                          |
| `hasLayers`         | `boolean` | `true`                                                         | Whether every rule goes into `<prefix>-theme`, `-global`, `-components` or `-overrides`                                                    |
| `hasPruning`        | `boolean` | `true`                                                         | Whether a theme class declares only the variables in use, appending more as rules come in                                                  |
| `hasBaseClass`      | `boolean` | `true`                                                         | Whether a styled component's styles are split into a base class and a props class                                                          |
| `hasDevChecks`      | `boolean` | on in development, with a `document`                           | Whether the cache checks the page and the declarations it inserts, and warns once for each problem                                         |
| `tokenSignature`    | `string`  | `''`                                                           | Set by the engine: a hash of its token options, part of the stamp of options that the server writes and the browser compares               |
| `hasColorFallbacks` | `boolean` | `true`                                                         | Whether a property whose value is `alpha()` gets a fallback declaration first                                                              |
| `hasValueRepair`    | `boolean` | `false`                                                        | Whether `var(--x)1F`, `-var(--x)`, `var(--x)ms` and `var(--x)s` are rewritten as `alpha()`, `negate()` and a `calc()` of a time write them |
| `hasScope`          | `boolean` | `true`                                                         | Whether conditional rules use `@scope`                                                                                                     |
| `sheet`             | `Sheet`   | a DOM sheet when `document` exists, otherwise an in-memory one | Where rules go                                                                                                                             |

A `Sheet` has `insert(rule)`, a readonly `rules` list, and optionally `replace(index, rule)` and `remove(index)`. Without `remove`, released global rules stay, and so does every class made from a plain object in `style` (see [No inline styles](no-inline-styles.md)). `createMemorySheet()` and `createDomSheet(key, container = document.head)` make the two sheets that the package has. A sheet may have a `document`: the document whose style element holds its rules. `createDomSheet` gives the document of its container, and the cache then reads that document (an iframe's) instead of the global one; see [The cache and server packages](cache-and-server.md).

## Binding options

| Name                     | Type            | Default | Effect                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------ | --------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `engine`                 | `Engine<Theme>` | none    | An engine to use, and to share with another binding. When given, the engine options in the same call are not used                                                                                                                                                                                                                                                                                                                                                     |
| `theme`                  | the theme       | none    | `configure` only: the base theme of the default style                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `hasServerStyleElements` | `boolean`       | `true`  | React only (client build): where there is no `document` (a server render), a styled element and a theme provider also render the `<style href precedence>` elements of their classes, as the server components build does, so that a client component is styled in the first HTML. In the browser it changes nothing. Set it to `false` when a classic server render sends the CSS of the page in one element of its own. See [Server rendering](server-rendering.md) |

`configure` throws if the default style has been used already.

## `styled` options

| Name                | Type                        | Default                                                                                                                                                                                                                                               | Effect                                                                                                                                                                         |
| ------------------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`              | `string`                    | none                                                                                                                                                                                                                                                  | With `slot`, the label of the class: `name-slot` in kebab-case. Ignored on React Native                                                                                        |
| `slot`              | `string`                    | `'root'`                                                                                                                                                                                                                                              | The part of the component this style is for. Ignored on React Native                                                                                                           |
| `shouldForwardProp` | `(prop: string) => boolean` | React: the attributes of HTML and SVG, `data-*`, `aria-*`, event handlers and React's own props (every prop to a custom element); Vue: every attribute. Never `as` (where it replaces a string tag), `theme`, `className` (`class` on Vue) or `style` | Which props reach a string tag; given, it replaces the default. On React it applies to a component too, and on React Native to every component, where `className` is forwarded |
| `target`            | `string`                    | none                                                                                                                                                                                                                                                  | A class of your own on the element, after the engine's classes; a wrapping component keeps it and adds its own. Web only (React and Vue)                                       |

## `ThemeProvider` props

| Name          | Type                                | React | Vue              | React Native | Default | Effect                                                                                                                                                                                 |
| ------------- | ----------------------------------- | ----- | ---------------- | ------------ | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `theme`       | `ThemeInput<Theme>`                 | yes   | yes              | yes          | none    | The theme, or the part of it that this subtree changes, or a function of the theme above that returns it                                                                               |
| `colorScheme` | `'light' \| 'dark' \| 'light dark'` | yes   | yes              | yes          | none    | Sets `color-scheme` (web: on `:root` for the outermost provider, else in its theme class) and the scheme marker class of a nested provider; the scheme for `whenScheme` (React Native) |
| `className`   | `string`                            | yes   | no (use `class`) | ignored      | none    | Added to the classes of the wrapper of a nested provider                                                                                                                               |
| `as`          | `string`                            | yes   | yes              | no           | `'div'` | The element of the wrapper of a nested provider                                                                                                                                        |
| `isRoot`      | `boolean`                           | yes   | yes              | ignored      | `false` | Renders no element, no class and no rule: see [The root theme and switching](root-theme.md)                                                                                            |

On the web the outermost provider (none above it) renders no element and declares its theme on `:root`; a nested one renders its wrapper. See [Themes](themes.md). `ThemeScope` takes only children (a default slot in Vue).

## Other signatures with options

| Call                                     | Argument                                           | Effect                                                                               |
| ---------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `engine.themeClass(theme, colorScheme?)` | `colorScheme`: `'light' \| 'dark' \| 'light dark'` | Sets `color-scheme` in the theme class. `light` and `dark` add a scheme marker class |
| `engine.when(theme, colorScheme?)`       | same                                               | The `colorScheme` must match the one given to the provider                           |
| `alpha(color, opacity)`                  | `opacity`: 0 to 1                                  | Outside the range throws a `RangeError`                                              |
| `createDomSheet(key, container?)`        | `key`: string                                      | The `data-style` of the style element it uses or creates                             |
| `createDomSheet(key, container?)`        | `container`: `Node`, default `document.head`       | Where the element is created; the element is looked up in the document of it         |
| `<CacheProvider value={cache}>`          | `value`: a cache                                   | The cache of the subtree; under it no server style element is rendered (React)       |
