# umber-style

The UmberStyle umbrella: it only re-exports the engine and the bindings as `umber-style`, `umber-style/react`, `umber-style/react-native` and `umber-style/vue`.

Install: `pnpm add umber-style`.

```ts
import { styled, ThemeProvider } from 'umber-style/react'
```

Documentation: [docs](../../docs/README.md). `umber-style/react` is the entry for code shared by the web and React Native: see [style sheets and the style prop](../../docs/style-sheets.md).
