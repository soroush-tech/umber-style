## umber-style@0.1.0

First release. One package for the whole of UmberStyle: it re-exports the engine at its root and each binding as a subpath. It holds no logic of its own.
([#9](https://github.com/soroush-tech/umber-style/issues/9))

### Added

- **`umber-style`** (the engine), **`umber-style/react`**, **`umber-style/react-native`** and **`umber-style/vue`**.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/README.md#the-packages)
- `umber-style/react` is the entry for code that runs on the web and on React Native: the export conditions pick the web binding, its server build, or the React Native binding, and its types are the ones both platforms share. `useTheme` is in those types under every condition, the server build's too, where it returns the base theme; `readTheme` is typed under the `react-server` condition only.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md)
- **`keyframes`**, **`globalStyles`** and **`Global`** in every binding entry and in the shared types of `umber-style/react` (the server entry too), with **`ThemeScope`**, **`useThemeClass`** and **`ThemeContext`** where the platform has them: not in the server build.
  ([#12](https://github.com/soroush-tech/umber-style/issues/12), [#46](https://github.com/soroush-tech/umber-style/issues/46))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/animations-and-global-styles.md)
- ESM and CommonJS builds with declarations.
- **`css`** in every subpath; in the types of `umber-style/react` it is a sheet entry on the web and a native style on React Native, and the theme is the `Theme` of `@umber-style/react`.
  ([#36](https://github.com/soroush-tech/umber-style/issues/36))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md)
- **`CacheProvider`** in `umber-style/react` (web and React Native) and `umber-style/vue`.
  ([#38](https://github.com/soroush-tech/umber-style/issues/38))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md)
- The `label` option, function styles that return a list, a later `undefined` value that does not erase an earlier one, and tag shorthands that `Object.assign` copies, through every subpath.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md)

### Packaging

- Depends on `@umber-style/core`, `@umber-style/react`, `@umber-style/react-native` and `@umber-style/vue`, none of them bundled.
- Optional peer dependencies: `react` `^19.2.8` and `vue` `^3.5.0`.
