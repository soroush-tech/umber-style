## umber-style@0.4.0

Hover, press, focus and disabled styles written once in a shared style, through the bindings and the core 0.4.0.
([#42](https://github.com/soroush-tech/umber-style/issues/42))

### Added

- **`state`** in every entry, with the types **`StateName`**, **`StateKey`** and **`StateProps`** in `umber-style/react`: `...at(state('pressed'), { opacity: 0.7 })` is the selector written by hand on the web (`&:active`) and the state of the component on React Native. A shared styled component takes the props `pressed`, `hovered` and `focused`, which React Native reads for a component that does not report the state itself.
  ([#42](https://github.com/soroush-tech/umber-style/issues/42))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#interaction-states)

### Packaging

- Depends on `@umber-style/core` `^0.4.0`, `@umber-style/react` `^0.4.0`, `@umber-style/react-native` `^0.4.0`, `@umber-style/vue` `^0.4.0` (it was `^0.3.0`).
