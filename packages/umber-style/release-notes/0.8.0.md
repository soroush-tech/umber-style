## umber-style@0.8.0

Released for the version that every package of the family carries, with a root that holds only what apps use.
([#75](https://github.com/soroush-tech/umber-style/issues/75), [#79](https://github.com/soroush-tech/umber-style/issues/79))

### Changed

- **Breaking: the root of `umber-style` no longer exports the helpers the bindings share.** It re-exports the main entry of `@umber-style/core`, from which they moved to `@umber-style/core/internal` (the release notes of `@umber-style/core@0.8.0` list each name). What an app imports instead: nothing, they are for the bindings. The root does not re-export the internal entry.
  ([#79](https://github.com/soroush-tech/umber-style/issues/79))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/plain-javascript.md#everything-umber-stylecore-exports)
