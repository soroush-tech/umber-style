## umber-style@0.3.0

A release for the new range of its dependencies, with nothing changed in this package.
([#48](https://github.com/soroush-tech/umber-style/issues/48))

### Changed

- Through `@umber-style/react` and `@umber-style/vue` 0.3.0, a nested provider declares only what the nested providers above it and it change, and follows the class on `<html>` for the rest.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/themes.md#the-provider)
- **Breaking for code that passed `hasRuleText`**: through the bindings and `@umber-style/core` 0.3.0, the option is named **`speedy`**, with the opposite meaning (`speedy: true` writes with `insertRule`, as `hasRuleText: false` did). In development an options object that still has `hasRuleText` gets one warning, and its value is not read. Outside production each rule is the text of a style element of its own.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/options.md#speedy)
- Through `@umber-style/core` 0.3.0, a theme switched while a page streams stays: a style element that arrives later with the root rule of the server no longer undoes the switch until the next declaration of the root theme.
  ([#48](https://github.com/soroush-tech/umber-style/issues/48))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)
- Through `@umber-style/core` 0.3.0, the `nonce` option of a cache, for a content security policy that allows style elements by nonce.
  ([#13](https://github.com/soroush-tech/umber-style/issues/13))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md#content-security-policy)
- Through `@umber-style/vue` 0.3.0, `umber-style/vue` exports `useStyleValue`, and the root entry the values of the core it is made of. `umber-style/react` keeps the types of one source for the web and React Native, which has no `useStyleValue` (React Native has no CSS variable): import it from `@umber-style/react` for web code.
  ([#53](https://github.com/soroush-tech/umber-style/issues/53))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#a-value-that-changes-without-a-render)

### Packaging

- Depends on `@umber-style/core` `^0.3.0`, `@umber-style/react` `^0.3.0`, `@umber-style/react-native` `^0.3.0`, `@umber-style/vue` `^0.3.0` (it was `^0.2.0`).
