## umber-style@0.5.0

Animations on React Native from one shared style, through the animated entry of the binding.
([#43](https://github.com/soroush-tech/umber-style/issues/43))

### Added

- **`umber-style/react-native/animated`**: the animated entry of `@umber-style/react-native` (`animated`) as a subpath.
  ([#43](https://github.com/soroush-tech/umber-style/issues/43))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#turning-it-on)
- **`MotionOptions`**: the shared `createStyle` and `configure` of `umber-style/react` take `animated`, which React Native reads and the web accepts and ignores, so one style module passes it on both platforms. The animation and transition keys are in the shared style types.
  ([#43](https://github.com/soroush-tech/umber-style/issues/43))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#turning-it-on)

### Packaging

- Depends on `@umber-style/core` `^0.5.0`, `@umber-style/react` `^0.5.0`, `@umber-style/react-native` `^0.5.0`, `@umber-style/vue` `^0.5.0` (it was `^0.4.0`).
