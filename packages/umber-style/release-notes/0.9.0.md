## umber-style@0.9.0

Released for the version that every package of the family carries; `css()` of each binding, given a function, says what to use instead.
([#85](https://github.com/soroush-tech/umber-style/issues/85), [#87](https://github.com/soroush-tech/umber-style/issues/87))

### Changed

- `css()` of `umber-style/react`, `umber-style/react-native` and `umber-style/vue` given a function throws one message on both platforms, which names `css` and what takes a function: a styled component's style function for a value of the props, an entry of `StyleSheet.create((theme) => ...)` given to the `style` prop for a value of the theme. See the notes of `@umber-style/react`.
  ([#87](https://github.com/soroush-tech/umber-style/issues/87))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#css)
