## umber-style@0.9.0

Released for the version that every package of the family carries; `css()` of each binding, given a function, says what to use instead; `style={sheet.card}` takes a handle of a sheet of the theme on both platforms, and `SheetStyleProp` types a style prop of entries only in shared code; `withTheme` and `withStyle` give a class component the theme and the entries of a sheet on both platforms.
([#85](https://github.com/soroush-tech/umber-style/issues/85), [#87](https://github.com/soroush-tech/umber-style/issues/87), [#88](https://github.com/soroush-tech/umber-style/issues/88), [#89](https://github.com/soroush-tech/umber-style/issues/89), [#93](https://github.com/soroush-tech/umber-style/issues/93))

### Added

- **`SheetStyleProp`** and **`ThemedEntry`** (types) of `umber-style/react` - a `style` prop of entries only in one source for web and mobile: an entry, a handle, `false`, `null`, `undefined` and nested lists, under the `react-native` export condition and without it. `StyleSheet.create((theme) => ...)` gives a handle for each name, which the `style` of a styled component takes on both platforms. See the notes of `@umber-style/react` and `@umber-style/react-native`.
  ([#88](https://github.com/soroush-tech/umber-style/issues/88))
  ([#89](https://github.com/soroush-tech/umber-style/issues/89))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#sheet-entries-only)
- **`withTheme`** and **`withStyle`** of `umber-style/react` and `umber-style/react-native` - `useTheme()` and `useStyle(sheet)` as the `theme` and `styles` props of a class component, typed in shared code under the `react-native` export condition, without it, and under `react-server`. One source runs on both platforms; each gets the wrappers of its binding. Vue keeps its composables. See the notes of `@umber-style/react` and `@umber-style/react-native`.
  ([#93](https://github.com/soroush-tech/umber-style/issues/93))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react.md#class-components-withtheme-and-withstyle)

### Changed

- `css()` of `umber-style/react`, `umber-style/react-native` and `umber-style/vue` given a function throws one message on both platforms, which names `css` and what takes a function: a styled component's style function for a value of the props, an entry of `StyleSheet.create((theme) => ...)` given to the `style` prop for a value of the theme. See the notes of `@umber-style/react`.
  ([#87](https://github.com/soroush-tech/umber-style/issues/87))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#css)
- `SharedEntry` is a sheet entry or a native entry of the React Native binding (`NativeSheetEntry`), and `SharedStyleProp` takes a handle. The type test that asserted `sheet.box` of a function sheet to be an error was changed to assert the handle.
  ([#88](https://github.com/soroush-tech/umber-style/issues/88))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#a-sheet-of-the-theme-without-a-hook)
