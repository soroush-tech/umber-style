## @umber-style/react@0.3.0

`useStyleValue` for a value that changes without a render, and style elements that carry a nonce for a strict content security policy.
([#53](https://github.com/soroush-tech/umber-style/issues/53)) ([#13](https://github.com/soroush-tech/umber-style/issues/13))

### Added

- **`useStyleValue(initial, unit?)`**, of the default style and of `createStyle`: `[value, setValue]`, as `useState` gives. In a style the value is a reference to a CSS variable of the component's own, so its class does not change; `setValue(next)` and `setValue((previous) => next)` change the declaration of the variable in place and render nothing; `value.get()` is the number. A server render shows the first number with no rule. In the server components build the setter does nothing, with a warning in development. The type **`StyleValueSetter`**.
  ([#53](https://github.com/soroush-tech/umber-style/issues/53))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#a-value-that-changes-without-a-render)
- The **`nonce`** option of `createStyle` and `configure`: the style element of the engine in the browser and every `<style href precedence>` element of both builds (styled classes, animations, `Global`, providers) carry it. Give React's render the same nonce as its style nonce.
  ([#13](https://github.com/soroush-tech/umber-style/issues/13))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md#content-security-policy)

### Changed

- Through `@umber-style/core` 0.3.0, a theme switched while a page streams stays: a style element that arrives later with the root rule of the server no longer undoes the switch until the next declaration of the root theme.
  ([#48](https://github.com/soroush-tech/umber-style/issues/48))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)

### Fixed

- A theme whose object refers to itself, given to a provider of the server components build, no longer recurses for ever when it is made plain data for client components: the member that closes the cycle is left out, and listed in the warning, as a function is.

### Packaging

- Depends on `@umber-style/core` `^0.3.0`, `@umber-style/is-prop-valid` `^0.3.0` (it was `^0.2.0`).
