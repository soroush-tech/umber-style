# @umber-style/styled

The legacy entry, kept for code that imports `styled` as a default export; new code imports `styled` from `@umber-style/react`.

Install: `pnpm add @umber-style/styled @umber-style/react`.

```tsx
import styled from '@umber-style/styled'

const Card = styled.div({ padding: 16, borderRadius: 8 })
```

Documentation: [docs](../../docs/README.md), and [Writing styles](../../docs/writing-styles.md#tag-shorthands) for `styled`.
