## @umber-style/styled@0.5.0

A release for the version that every package of the family carries and the new range of its dependencies and of React, with no change to its code.
([#43](https://github.com/soroush-tech/umber-style/issues/43))

### Changed

- A strict nonce policy on a page rendered on a server needs React 19.2 or later: before 19.2 React writes no nonce on the style elements it hoists (the `<style href precedence>` elements of styled components and providers), and the browser refuses them.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md#content-security-policy)

### Packaging

- The peer range of `react` is `^19.0.0` (it was `^19.2.8`): the whole suite runs on each React 19 minor, 19.0 to 19.3.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/getting-started.md)
- Depends on `@umber-style/react` `^0.5.0` (it was `^0.4.0`).
