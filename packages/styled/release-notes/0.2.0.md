## @umber-style/styled@0.2.0

A release for the new range of its dependency on the React binding, with nothing changed in this package.
([#52](https://github.com/soroush-tech/umber-style/issues/52))

### Changed

- Through `@umber-style/react` 0.2.0, a string tag forwards the props that `@umber-style/is-prop-valid/react` is true for, a wider list than before: older spellings such as `class` and `for`, `x-*`, `data-*` and `aria-*` in any case, `on` followed by a digit or a sign, and more legacy and newer attributes. Two copies of the binding in one program share its default style, and so this `styled`.
  ([#56](https://github.com/soroush-tech/umber-style/issues/56))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#which-props-reach-the-element)

### Packaging

- Depends on `@umber-style/react` `^0.2.0` (it was the exact `0.1.0`): it is declared `workspace:^`. A patch of the binding now reaches this package without a release of its own, and an app keeps one default style.
- MINOR, with the React binding: its default filter is wider and it has a new dependency.
- Peer dependency: `react` `^19.2.8`, unchanged.
