## @umber-style/styled@0.1.0

First release. `styled` as the default export, for code that imports it as `import styled from '...'`.
([#45](https://github.com/soroush-tech/umber-style/issues/45))

### Added

- **The default export `styled`**: the `styled` of the default style of `@umber-style/react`, the same function, with the tag shorthands (`styled.div`). Under the `react-server` condition it is the `styled` of the server build.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md)
- The types of `styled`: **`Styled`**, **`StyledComponent`**, **`StyledFactory`**, **`StyledOptions`**, **`StyledStatics`**, **`StyledTags`** and **`StyleProp`**.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#the-type-names-apps-import)
- ESM and CommonJS builds with declarations.
- The template form, and the types **`CreateStyled`**, **`FilteringStyledOptions`**, **`PropsOf`**, **`CSSObject`**, **`Interpolation`** and **`Theme`**.
  ([#47](https://github.com/soroush-tech/umber-style/issues/47)) ([#49](https://github.com/soroush-tech/umber-style/issues/49))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md)
- The type **`CreateStyledComponent`**, and the tag shorthands as own members of the default export, so that `Object.assign(wrapper, styled)` copies them.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#a-wrapper-of-styled)

### Packaging

- Depends on `@umber-style/react`, which is not bundled, so the app has one default style.
- Peer dependency: `react` `^19.2.8`.
