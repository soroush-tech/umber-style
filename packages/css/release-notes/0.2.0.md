## @umber-style/css@0.2.0

`createInstance({ cache })` takes a cache of `@umber-style/cache` as it is, with no cast, and the default instance is one for the program.
([#52](https://github.com/soroush-tech/umber-style/issues/52))

### Fixed

- **`createInstance`** of `@umber-style/css/create-instance` accepts the cache that `createCache({ key })` of `@umber-style/cache` makes. `SharedCache` takes a `sheet` member that is the cache's style elements (`UmberSheet`), where the type asked for a sheet of the core and only `as unknown as SharedCache` compiled. Given such a cache and no `sheet`, the instance's `sheet` is typed `UmberSheet`, which is what it already was at run time (`CssInstance` takes the type of its sheet, `Sheet` by default). Its classes are in the cache's layers when the cache has them.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/css.md#a-shared-cache)
- The default instance is shared by every copy of the package in the program: a class that one copy made is merged by `cx` and extracted by another.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/how-it-works.md#two-copies-in-one-program)

### Packaging

- Depends on `@umber-style/core` `^0.2.0` (it was the exact `0.1.0`): it is declared `workspace:^`. A patch of the core now reaches this package without a release of its own, and an app keeps one copy.
- MINOR, with the core, which has new public API.
