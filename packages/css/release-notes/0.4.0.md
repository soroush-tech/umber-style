## @umber-style/css@0.4.0

A release for the version that every package of the family carries and the new range of its dependency, with nothing changed in this package.
([#42](https://github.com/soroush-tech/umber-style/issues/42))

### Changed

- An instance's style element is made at its first rule, not when the instance is made: an instance that writes nothing adds nothing to the page. After `flush` the element stays, empty, for the next rule. ([#13](https://github.com/soroush-tech/umber-style/issues/13))

### Packaging

- Depends on `@umber-style/core` `^0.4.0` (it was `^0.3.0`).
