## @umber-style/css@0.1.0

First release. The plain layer under the engine: a style goes to a cache and comes back as a class name, with no theme, no variables and no provider. It is built on the cache and the serializer of `@umber-style/core`.
([#50](https://github.com/soroush-tech/umber-style/issues/50))

### Added

- **`css`, `cx`, `keyframes`, `injectGlobal`**, with style objects, lists, class names to merge and tagged templates; **`cache`, `sheet`, `flush`, `hydrate`, `getRegisteredStyles`, `merge`**.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/css.md)
- **`@umber-style/css/create-instance`**: a separate instance with its own key, or over a cache that other code shares.
- Rules are written outside every cascade layer by default, so that a class behaves as an ordinary class next to the app's own CSS.
- ESM and CommonJS builds with declarations.

### Packaging

- Depends on `@umber-style/core`, which is not bundled.
