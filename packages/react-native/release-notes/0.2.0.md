## @umber-style/react-native@0.2.0

Two copies of the binding in one program share its default style and the ids of `when(theme)`.
([#52](https://github.com/soroush-tech/umber-style/issues/52))

### Added

- `@umber-style/is-prop-valid/react-native`, a filter of the props of React Native's built-in components, can be given as `shouldForwardProp`. The default of the binding is unchanged: every prop is forwarded.
  ([#56](https://github.com/soroush-tech/umber-style/issues/56))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/prop-filters.md#react-native)

### Fixed

- `when(theme)` of two copies gave the same id to two themes, so a condition of one copy could hold for the theme of the other. The ids are now counted once for the program.
- The default style (`styled`, `ThemeProvider`, `configure` and the rest) is one for the program: a component of one copy reads the provider of another.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/how-it-works.md#two-copies-in-one-program)

### Packaging

- Depends on `@umber-style/core` `^0.2.0` (it was the exact `0.1.0`): it is declared `workspace:^`. A patch of the core now reaches this package without a release of its own, and an app keeps one copy.
- MINOR, with the core, which has new public API.
- Peer dependencies: `react` `^19.2.8` and `react-native` `>=0.76.0` (optional), unchanged.
