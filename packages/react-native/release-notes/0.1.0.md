## @umber-style/react-native@0.1.0

First release. The React Native binding of UmberStyle: the same names as the React binding, over the real theme values, since React Native has no CSS.
([#9](https://github.com/soroush-tech/umber-style/issues/9))

### Added

- `styled`, `ThemeProvider`, `useTheme`, `StyleSheet`, `useStyle` and `apply`, with the style types of React Native.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md)
- **`keyframes`**, **`globalStyles`** and **`Global`**, so that one source compiles on the web and on React Native: `keyframes` returns the same name as on the web, `Global` renders nothing, and the `animation*` and `transition*` keys of a style are dropped.
  ([#12](https://github.com/soroush-tech/umber-style/issues/12))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/animations-and-global-styles.md)
- A theme can be a function of the theme above. **`ThemeScope`** (its children), **`useThemeClass`** (`undefined`) and **`ThemeContext`**, for the same source as the web; with no provider, `useTheme` gives the base theme, or an empty object.
  ([#46](https://github.com/soroush-tech/umber-style/issues/46))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/themes.md)
- Values with CSS units: a length in `px`, in `rem` (times the `remBase` option, default 16) or with no unit becomes a number, in the theme (under the length keys, once for each theme object) and in styles; `NativeTheme<T>` types the theme that is read.
  ([#40](https://github.com/soroush-tech/umber-style/issues/40))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#values-with-css-units)
- A development warning, once for each message and with the name of the component, about a web-only key written outside the `web` part of a style (a selector, an at-rule, a custom property, an animation or transition key), and about `em`, viewport units, `calc()` and `currentColor`, which have no equivalent.
  ([#39](https://github.com/soroush-tech/umber-style/issues/39))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#development-warnings)
- ESM and CommonJS builds with declarations.

### Packaging

- Depends on `@umber-style/core`, which is not bundled, so every package shares one engine.
- Peer dependencies: `react` `^19.2.8`, and `react-native` `>=0.76.0` (optional).
- The binding has not been run in a real React Native app yet: see the Limits of the React Native page.
