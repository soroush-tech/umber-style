## @umber-style/react-native@0.1.0

First release. The React Native binding of UmberStyle: the same names as the React binding, over the real theme values, since React Native has no CSS.
([#9](https://github.com/soroush-tech/umber-style/issues/9))

### Added

- `styled`, `ThemeProvider`, `useTheme`, `StyleSheet`, `useStyle` and `apply`, with the style types of React Native.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md)
- ESM and CommonJS builds with declarations.

### Packaging

- Depends on `@umber-style/core`, which is not bundled, so every package shares one engine.
- Peer dependencies: `react` `^19.2.8`, and `react-native` `>=0.76.0` (optional).
- The binding has not been run in a real React Native app yet: see the Limits of the React Native page.
