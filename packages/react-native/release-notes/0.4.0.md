## @umber-style/react-native@0.4.0

The state keys of the core on React Native: a style follows what the component is doing, with nothing written in the component.
([#42](https://github.com/soroush-tech/umber-style/issues/42))

### Added

- **`state`**, with the types **`StateName`** and **`StateKey`**, exported from the core: `...at(state('pressed'), { opacity: 0.7 })` in a style. On React Native each key is a condition the binding evaluates. A `Pressable` whose styles name `pressed` gets `style` as a function of its `{ pressed }`, so the platform's own state drives it; a pressable whose styles name no state keeps getting an array, and a press does not render it again. `disabled` follows `disabled`, `aria-disabled`, `accessibilityState.disabled` and `editable={false}`. `hovered` and `focused` are kept from `onHoverIn` and `onHoverOut`, `onFocus` and `onBlur` for a component whose object styles name them, and the component's own handlers are still called; `hovered` applies only where the platform reports hover, and `focused` is any focus.
  ([#42](https://github.com/soroush-tech/umber-style/issues/42))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#interaction-states)
- **`StateProps`**: the props `pressed`, `hovered` and `focused` of a styled component, which tell the state to a component that does not report it itself. Where the styles name a state the binding reads them and does not forward them, unless `shouldForwardProp` returns true for the name.
  ([#42](https://github.com/soroush-tech/umber-style/issues/42))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#interaction-states)

### Changed

- A style with state or condition keys is resolved once for each theme of the provider, color scheme, set of matching queries and set of states, and the same style object is given again after, with the same values ([#10](https://github.com/soroush-tech/umber-style/issues/10)). In `bench/states-pressables.bench.ts` (its sandbox, the median of three rounds) a render of 48 pressables with state keys went from 113 us to 60 us (48 with no state key take 46 us), and a press from 1.65 us to 441 ns.

### Packaging

- Depends on `@umber-style/core` `^0.4.0` (it was `^0.3.0`).
