## @umber-style/react-native@0.6.0

The theme below a provider is the same object for the same themes, and the binding exports `setNonceSource`, which React Native does not read, so that every binding has the same names.
([#64](https://github.com/soroush-tech/umber-style/issues/64))

### Added

- **`setNonceSource`** (the core's), exported so that every binding has the name: React Native has no style elements, and nothing here reads it.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md#server-components-a-nonce-for-each-request)

### Packaging

- Depends on `@umber-style/core` `^0.6.0` (it was `^0.5.0`).
