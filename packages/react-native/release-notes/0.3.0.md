## @umber-style/react-native@0.3.0

A failed answer of the platform about reduced motion leaves no rejection unhandled.
([#48](https://github.com/soroush-tech/umber-style/issues/48))

### Changed

- The option `hasRuleText` of the web bindings is named `speedy` (with the opposite meaning). React Native does not use it; given, it is named in the development warning of the options React Native does not use, as before.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/options.md#speedy)
- Through `@umber-style/core` 0.3.0, a theme switched while a page streams stays on the web; nothing changes on React Native.
  ([#48](https://github.com/soroush-tech/umber-style/issues/48))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)
- The `nonce` option of the web bindings is named in the development warning of the options React Native does not use, as the other web options are.

### Fixed

- When the platform fails to answer whether reduced motion is on, the binding keeps the value it had (no preference at first), and the rejection is handled; a later change of the setting is still followed.

### Packaging

- Depends on `@umber-style/core` `^0.3.0` (it was `^0.2.0`).
