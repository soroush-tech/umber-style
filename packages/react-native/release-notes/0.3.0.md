## @umber-style/react-native@0.3.0

A release for the new range of its dependencies, with nothing changed in this package.
([#48](https://github.com/soroush-tech/umber-style/issues/48))

### Changed

- Through `@umber-style/core` 0.3.0, the root theme of a page that streams stays one rule: a style element that arrives after the browser declared the root theme no longer keeps root rules that override a theme given later.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)

### Packaging

- Depends on `@umber-style/core` `^0.3.0` (it was `^0.2.0`).
