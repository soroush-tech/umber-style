## @umber-style/core@0.5.0

The steps of an animation can be read back by name, for the animated entry of React Native, which runs them through the platform's animation library.
([#43](https://github.com/soroush-tech/umber-style/issues/43))

### Added

- **`readKeyframesSteps(name)`**: the steps registered under a name that `keyframes` returned, as they were given (an object, or a function of the theme), or `undefined` for any other name. Nothing else of `keyframes` changed: the names, the rules and when they are written are as they were.
  ([#43](https://github.com/soroush-tech/umber-style/issues/43))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react-native.md#animations)

### Fixed

- **`findMissingStyles`**, and so the development checker of a cache, read a class name only up to its first upper-case letter, so every class with a label that has one (`<prefix>-View-flex-x1`) was reported as having no rule although the page had it. It now reads every character that a class name of the engine can hold, letters of either case and letters past ASCII, and reads the escapes that a browser keeps in the text of a selector; the names of variables are read the same way. A class that no rule names is still reported.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/testing.md#the-development-checker)

### Packaging

- No dependency of the family; `csstype` as before.
