## @umber-style/core@0.3.0

The root theme of a page that streams stays one rule: a switch of the theme in the browser takes effect on a page whose content arrived in chunks.
([#48](https://github.com/soroush-tech/umber-style/issues/48))

### Fixed

- A style element that arrives after the cache declared its root theme (a chunk that a framework streams into the body, with the rules a registry collected for it) no longer keeps its `:where(:root)` rules. They came later in the document than the rule of the cache and won with the values the server sent, so a theme given to the outermost provider afterwards did not show. The cache removes them as the element arrives; its other rules are kept.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)

### Packaging

- No dependency on a sibling. Released as 0.3.0 with every package of the family, which carry one version.
