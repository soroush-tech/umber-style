# @umber-style/vue

The Vue binding of UmberStyle: the same names as the React binding, with a reactive `useTheme`.

Install: `pnpm add @umber-style/vue`.

```ts
import { styled, ThemeProvider } from '@umber-style/vue'
```

Documentation: [docs](../../docs/README.md), and [Vue](../../docs/vue.md) for this package.
