## @umber-style/vue@0.4.0

The state keys of the core in the Vue binding, for styles that one source shares with React Native.
([#42](https://github.com/soroush-tech/umber-style/issues/42))

### Added

- **`state`**, with the types **`StateName`** and **`StateKey`**, exported from the core: `...at(state('pressed'), { opacity: 0.7 })` in a style is the class and the rules of `'&:active'` written by hand, and so for `hovered` (`&:hover`), `focused` (`&:focus-visible`) and `disabled` (`&:disabled, &[aria-disabled="true"]`). No JavaScript runs for them; server rendering and extraction write the same CSS.
  ([#42](https://github.com/soroush-tech/umber-style/issues/42))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#interaction-states)

### Changed

- A style of the binding adds no style element to the page until its cache writes a rule, as the core now does: a style that writes nothing to its own cache (everything under a `CacheProvider`) adds none. ([#13](https://github.com/soroush-tech/umber-style/issues/13))

### Packaging

- Depends on `@umber-style/core` `^0.4.0` (it was `^0.3.0`).
