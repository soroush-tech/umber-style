## @umber-style/vue@0.9.0

Released for the version that every package of the family carries; `css()` given a function says what to use instead; the style of a styled component takes a handle of a sheet made from a function of the theme, and `StyleProp` and `SheetStyleProp` are exported.
([#85](https://github.com/soroush-tech/umber-style/issues/85), [#87](https://github.com/soroush-tech/umber-style/issues/87), [#88](https://github.com/soroush-tech/umber-style/issues/88), [#89](https://github.com/soroush-tech/umber-style/issues/89))

### Added

- **`style={sheet.card}`: a handle of a sheet made from a function of the theme.** Each name of `StyleSheet.create((theme) => ...)` is a handle, a frozen object that holds the sheet and the name and computes nothing. The `style` of a styled component, in the browser and in a server render, resolves it with the theme it renders under, alone, in lists and with falsy values, through the binding's own `useStyle`, so the class and the rules are exactly those of `style={useStyle(sheet).card}` under the same provider. `useStyle` and object sheets are unchanged.
  ([#88](https://github.com/soroush-tech/umber-style/issues/88))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#a-sheet-of-the-theme-without-a-hook)
- **`SheetStyleProp`** - the type of a `style` prop that takes sheet entries only: an entry (of `StyleSheet.create`, `useStyle` or `css()`), a handle, `false`, `null`, `undefined` and nested lists of them. A plain style object and a string are type errors. It is a part of `StyleProp`, so a component passes it on to its parts as it is.
  ([#89](https://github.com/soroush-tech/umber-style/issues/89))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#sheet-entries-only)
- **`StyleProp`** - what the `style` attribute of a styled component takes: entries, handles, plain style objects, falsy values and nested lists. The attribute of a styled component itself is still untyped.
  ([#89](https://github.com/soroush-tech/umber-style/issues/89))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#sheet-entries-only)

### Changed

- **`css()` given a function says what to use instead.** A function given to `css()`, as an argument (alone or in a list) or as an interpolation of its template, threw a `TypeError` that said only that `css()` has no props. It now throws one message on every path and in every binding, which names `css` and the two things that take a function:
  `css(): a function is not a style here, as an argument or as an interpolation: css() makes a class with no component, so it has no props or theme to call it with. For a value of the props, use a styled component's style function; for a value of the theme, give an entry of StyleSheet.create((theme) => ...) to the style prop.`
  With `css` of the default style the error comes at the first use of the value, where the entry is made, as before; with `css` of `createStyle()` it comes at the call. `css()` with no function in it is unchanged.
  ([#87](https://github.com/soroush-tech/umber-style/issues/87))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#css)
- **`sheet.card` of a sheet made from a function of the theme is a handle.** It was `undefined`, and a type error; it is now typed `ThemedEntry`, and a misspelt name is still a type error. The type tests that asserted the error were changed to assert the handle. Names that frameworks and serializers read on any object are not handles: the sheet's own members, the members of every object, `then`, `toJSON`, `$$typeof` and names that start with `__`.
  ([#88](https://github.com/soroush-tech/umber-style/issues/88))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#a-sheet-of-the-theme-without-a-hook)
- **A handle where no theme is known is a `TypeError`, in every build:** `apply`, `css()`, the styles of `styled`, `globalStyles` and `Global`. On a plain Vue element a handle writes nothing, as an entry does. The message names the place and the fix, for example `apply(): an entry of a sheet made from a function of the theme (StyleSheet.create((theme) => ...)) has no theme here. Give it to the style prop of a styled component, which resolves it with its theme, or read the entry from useStyle(sheet) first.`
  ([#88](https://github.com/soroush-tech/umber-style/issues/88))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/style-sheets.md#a-sheet-of-the-theme-without-a-hook)
