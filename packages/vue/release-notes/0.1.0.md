## @umber-style/vue@0.1.0

First release. The Vue binding of UmberStyle: the same names as the React binding, with a reactive `useTheme`.
([#9](https://github.com/soroush-tech/umber-style/issues/9))

### Added

- **`styled`**, **`ThemeProvider`**, **`useTheme`**, **`StyleSheet`**, **`useStyle`** and **`apply`**, with **`createStyle`** for a typed, separate engine and **`bindEngine`** for the same API over an engine made with the core.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/vue.md#getting-the-api)
- **`keyframes`**, **`globalStyles`** and **`Global`**: a `Global` writes its rules in `setup`, replaces them when what they read changes, and removes them when it unmounts. On a server it renders a comment that names its sets, `<!--<prefix>-global ...-->`, so that `extractPageStyles` puts them in that page only.
  ([#12](https://github.com/soroush-tech/umber-style/issues/12))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/animations-and-global-styles.md)
- The outermost `ThemeProvider` renders no element: its theme is declared on `:root`. A nested provider renders its wrapper. A theme can be a function of the theme above. **`ThemeScope`** and **`useThemeClass`** carry the wrapper of the nearest nested provider to content that is teleported.
  ([#46](https://github.com/soroush-tech/umber-style/issues/46))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/themes.md)
- ESM and CommonJS builds with declarations.
- **`css()`**, on the default style and on `createStyle()`.
  ([#36](https://github.com/soroush-tech/umber-style/issues/36))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/vue.md)
- The template form of `styled`, `css`, `keyframes` and `globalStyles`, and a styled component as a selector.
  ([#47](https://github.com/soroush-tech/umber-style/issues/47))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md)
- The types apps import: `Theme` (extends the core's), `CreateStyled`, `FilteringStyledOptions`, `PropsOf`, `Interpolation`, and the core's `CSSObject`, `Keyframes`, `SerializedStyles` and `UmberCache`.
  ([#49](https://github.com/soroush-tech/umber-style/issues/49))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md)
- **`CacheProvider`**: gives the components in its slot its cache, through `provide` and `inject`; its `value` is read once.
  ([#38](https://github.com/soroush-tech/umber-style/issues/38))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/vue.md)
- The `label` option and function styles that return a list. The tag shorthands are own members of `styled`, so `Object.assign(wrapper, styled)` copies them, and reading one does not use the default style.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md)
- The classes of a styled component carry the labels of every component that styled the element, inner first: a wrapper with a label of its own is `<prefix>-Inner-Outer-<hash>`, and an engine class that reaches a labelled root through `class` adds its labels after the root's. `as` on a styled component made from a component that is not made by `styled` is given to that component, which is always rendered; it still replaces a string tag.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/writing-styles.md#as)
- With no provider above, `useTheme()`, a function style and `Global` read the base theme given to `createStyle(theme)` or `configure({ theme })`, or the empty theme: the theme of a provider that unmounted is not read any more. `css()` values have `name` and `styles`, and `hasRuleText` is an option of `createStyle` and `configure`.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/themes.md#the-base-theme)
- **`StyleTypeOptions`** is re-exported: the web style types take an app's code as it is by default, and `declare module '@umber-style/vue'` with `isStrict: true` switches on the strict ones.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/typed-styles.md#the-default-types-and-the-strict-switch)
- `Global` writes a `css()` value, a function of the theme that returns one, and a list of them as global rules; under a cache provider a style keeps the options that describe how its styles are written.
  ([#52](https://github.com/soroush-tech/umber-style/issues/52))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/animations-and-global-styles.md#what-styles-takes)

### Packaging

- Depends on `@umber-style/core`, which is not bundled, so every package shares one engine.
- Peer dependency: `vue` `^3.5.0`.
