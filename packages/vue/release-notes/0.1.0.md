## @umber-style/vue@0.1.0

First release. The Vue binding of UmberStyle: the same names as the React binding, with a reactive `useTheme`.
([#9](https://github.com/soroush-tech/umber-style/issues/9))

### Added

- `styled`, `ThemeProvider`, `useTheme`, `StyleSheet`, `useStyle` and `apply`.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/vue.md)
- **`keyframes`**, **`globalStyles`** and **`Global`**: a `Global` writes its rules in `setup`, replaces them when what they read changes, and removes them when it unmounts.
  ([#12](https://github.com/soroush-tech/umber-style/issues/12))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/animations-and-global-styles.md)
- The outermost `ThemeProvider` renders no element: its theme is declared on `:root`. A nested provider renders its wrapper. A theme can be a function of the theme above. **`ThemeScope`** and **`useThemeClass`** carry the wrapper of the nearest nested provider to content that is teleported.
  ([#46](https://github.com/soroush-tech/umber-style/issues/46))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/themes.md)
- ESM and CommonJS builds with declarations.

### Packaging

- Depends on `@umber-style/core`, which is not bundled, so every package shares one engine.
- Peer dependency: `vue` `^3.5.0`.
