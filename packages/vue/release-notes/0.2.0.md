## @umber-style/vue@0.2.0

Two copies of the binding in one program share its default style and its `CacheProvider`.
([#52](https://github.com/soroush-tech/umber-style/issues/52))

### Added

- `@umber-style/is-prop-valid/vue`, a filter of the attributes as Vue writes them, can be given as `shouldForwardProp`. The default of the binding is unchanged: a string tag gets every attribute.
  ([#56](https://github.com/soroush-tech/umber-style/issues/56))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/prop-filters.md#vue)

### Fixed

- The default style (`styled`, `ThemeProvider`, `configure` and the rest) is one for the program, and so is the key under which `CacheProvider` provides its cache: a component of one copy reads the provider and the cache of another.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/how-it-works.md#two-copies-in-one-program)

### Packaging

- Depends on `@umber-style/core` `^0.2.0` (it was the exact `0.1.0`): it is declared `workspace:^`. A patch of the core now reaches this package without a release of its own, and an app keeps one copy.
- MINOR, with the core, which has new public API.
- Peer dependency: `vue` `^3.5.0`, unchanged.
