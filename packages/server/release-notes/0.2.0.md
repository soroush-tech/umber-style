## @umber-style/server@0.2.0

A release for the new range of its dependency on the core, with nothing changed in this package.
([#52](https://github.com/soroush-tech/umber-style/issues/52))

### Changed

- Through `@umber-style/core` 0.2.0, an instance extracts the `@keyframes` rule of a name that another copy of the core in the program returned. A styled component and a class of `@umber-style/css` over one cache of `@umber-style/cache`, given to the plain layer as it is, are extracted together by one instance, each in the layers of that cache (a test runs it).
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#a-static-or-server-page-createinstance)

### Packaging

- Depends on `@umber-style/core` `^0.2.0` (it was the exact `0.1.0`): it is declared `workspace:^`. A patch of the core now reaches this package without a release of its own, and an app keeps one copy.
- MINOR, with the core, which has new public API.
