## @umber-style/server@0.3.0

The style elements of a page carry the nonce of its cache, for a strict content security policy.
([#13](https://github.com/soroush-tech/umber-style/issues/13))

### Added

- **`constructStyleTagsFromChunks`** and **`renderStylesToString`** write the `nonce` of the cache (`createCache({ key, nonce })`) on each `<style data-umber>` element, escaped. The CSS of the chunks is the same with it or without.
  ([#13](https://github.com/soroush-tech/umber-style/issues/13))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md#content-security-policy)

### Changed

- Through `@umber-style/core` 0.3.0, a theme switched while a page streams stays: a style element that arrives later with the root rule of the server no longer undoes the switch until the next declaration of the root theme.
  ([#48](https://github.com/soroush-tech/umber-style/issues/48))
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/cache-and-server.md#limits)

### Packaging

- Depends on `@umber-style/core` `^0.3.0` (it was `^0.2.0`).
