## @umber-style/server@0.4.0

A release for the version that every package of the family carries and the new range of its dependency, and its function by name for the CommonJS build of a library.
([#42](https://github.com/soroush-tech/umber-style/issues/42))

### Added

- **`createInstance`** as a named export too: `createInstance` of `@umber-style/server/create-instance` (the default export), the same function. A library that is an ES module package and ships a CommonJS build imports it by name, since its bundler's interop gives the whole `module.exports`, an object, as the default. The default export and the CommonJS file are as they were.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/react.md#a-library-that-ships-a-commonjs-build)

### Packaging

- Depends on `@umber-style/core` `^0.4.0` (it was `^0.3.0`).
