## @umber-style/server@0.1.0

First release. The server functions of a cache, for a page that is rendered to a string: the CSS that page needs, as chunks and as style tags.
([#48](https://github.com/soroush-tech/umber-style/issues/48))

### Added

- **`@umber-style/server/create-instance`** (the default export): `createInstance(cache)` returns `extractCritical`, `extractCriticalToChunks`, `constructStyleTagsFromChunks` and `renderStylesToString`. The CSS of a page is decided from the class names in its HTML (a layer over `extractPageStyles` of `@umber-style/core`): the global rules in a `<key>-global` chunk, the rules of the classes in a `<key>` chunk, written as `<style data-umber="<key> <ids>">` elements.
  [docs](https://github.com/soroush-tech/umber-style/blob/main/docs/server-rendering.md)
- ESM and CommonJS builds with declarations.

### Packaging

- Depends on `@umber-style/core`, which is not bundled, so every package shares one engine.
